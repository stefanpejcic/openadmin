SMTP

Set up an SMTP server to send email notifications to administrators and OpenPanel user accounts. Email notifications won't be sent until this is configured.

Hostname or IP of the SMTP server. Unless "Use TLS" or "Use SSL" below is enabled, authenticated sending only works when this is set to localhost, sending credentials unencrypted to any other host is refused.
Common ports:
  • 25, unencrypted relay
  • 587, STARTTLS (pair with "Use TLS")
  • 465, implicit TLS (pair with "Use SSL")
Upgrades the connection with STARTTLS after connecting (typically port 587). Enable this if Server is anything other than localhost, otherwise authentication is refused.
Connects using implicit TLS/SSL from the start (typically port 465). Enable this if Server is anything other than localhost, otherwise authentication is refused.
Account used to authenticate with the SMTP server. Leave empty to send unauthenticated, which only works when Server is localhost.
Password for the account above. Stored in openpanel.config on this server.
The "From" address used on outgoing emails. Usually the same as Username above.

If enabled, sent emails are also stored as files in /var/log/openpanel/admin/emails/.
