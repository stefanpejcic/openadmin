AI Assistant

Chat assistant users open from the AI button in the OpenPanel top bar. It answers questions using the OpenPanel documentation and can look things up or make changes in the user's account.

{{if not .AIModuleEnabled}}

The AI Assistant module is disabled. Enable it on Settings > Modules and add it to the feature sets of the plans that should have it.

{{end}}

It can't see the user's data, it only explains how to do things.

It can list domains, websites, emails, usage and similar, but can't change anything.

Every change is shown to the user for approval first. Users can choose to always allow an action, but actions that delete or overwrite data always ask. Everything it does is written to the user's activity log.
