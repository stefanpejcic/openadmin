Security

Captcha, 2FA and password protections for login and signup forms.

Minimum password strength for all password input fields in OpenPanel: account, FTP, Emails, Databases..
1-100

Below 50, weak passwords are accepted. Recommended: at least 50.

When enabled, user passwords during account creation and password resets are checked against Weakpass.com's database of compromised passwords to improve security.

Recommended: on, so passwords found in known data breaches can't be used.

When enabled, users will have to setup '2FA' in their OpenPanel, before accessing any other pages. 2FA module needs to be enabled to enforce.
When enabled, a session cookie is rejected if the request's IP address doesn't match the IP it was issued to.

With this off, a session cookie stolen from a user, for example through phishing, can be reused by an attacker from any IP. Recommended: on.

AI assistant

Chat assistant users open from the AI button in the OpenPanel top bar. It answers questions using the OpenPanel documentation and can look things up or make changes in the user's account.

{{if not .AIModuleEnabled}}

The AI Assistant module is disabled. Enable it on Settings > Modules and add it to the feature sets of the plans that should have it.

{{end}}

It can't see the user's data, it only explains how to do things.

It can list domains, websites, emails, usage and similar, but can't change anything.

Every change is shown to the user for approval first. Users can choose to always allow an action, but actions that delete or overwrite data always ask. Everything it does is written to the user's activity log.
