Delete ?

This permanently removes the domain and its configuration. You can't undo this.

  • VHost configuration files are deleted
  • Caddyfile entries are removed
  • SSL certificates are deleted
  • Email accounts and redirects are deleted

Website files and the docroot directory are kept. If this domain is added again later, default configurations are recreated. Domains with attached websites can't be deleted, remove those websites in Site Manager first.

Suspend domain

Visitors of will see the page for the selected reason. The user can't unsuspend, edit or delete the domain until you unsuspend it.
