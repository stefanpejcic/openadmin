Ports

Make sure to open ports on the firewall.

{{template "macro_tooltip" (dict "ID" "2087_port" "Label" "OpenAdmin port" "Description" "Set port on which OpenAdmin (admin-level panel) will be accessible - default is 2087" "Required" false)}}

If using a custom port for admin panel, make sure to open it on the firewall.

{{if .ClusterMaster}}

This server is in the multi-server cluster of {{.ClusterMaster}}. After changing the port, remove it under System > Multi-Server on the master and add it again with the new port, the master can't reach it otherwise.

{{end}}
{{template "macro_tooltip" (dict "ID" "2083_port" "Label" "OpenPanel port" "Description" "Set port on which OpenPanel (end-user panel) will be accessible - default is 2083" "Required" false)}}
