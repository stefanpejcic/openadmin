Edit VirtualHost Templates

Edit the webserver, Varnish and Caddy configuration templates used for new domains.

Apache VirtualHost

Template used for creating VirtualHosts of domains added by users with Apache webserver.

docker_apache_domain.conf
Used for new domains, existing ones keep their current file. Changed from the default. Only for advanced users, add a test user and domain afterwards to check everything still works.

Nginx VirtualHost

Template used for creating VirtualHosts of domains added by users with Nginx webserver.

docker_nginx_domain.conf
Used for new domains, existing ones keep their current file. Changed from the default. Only for advanced users, add a test user and domain afterwards to check everything still works.

OpenResty VirtualHost

Template used for creating VirtualHosts of domains added by users with OpenResty webserver.

docker_openresty_domain.conf
Used for new domains, existing ones keep their current file. Changed from the default. Only for advanced users, add a test user and domain afterwards to check everything still works.

Varnish template

This default.vcl template is applied to Varnish instances created for new user accounts. The placeholder VARNISH_BACKEND_HOST is automatically replaced with the user's actual web server.

default.vcl
Used for new domains, existing ones keep their current file. Changed from the default. Only for advanced users, add a test user and domain afterwards to check everything still works.

Caddy VirtualHost

This template is applied to all newly added domains. The variables <DOMAIN_NAME> <SSL_PORT> <NON_SSL_PORT> are automatically replaced by OpenPanel during domain creation. Do not modify the comments, as they are used as markers for Dedicated IP and Varnish Caching.

domain.conf
Used for new domains, existing ones keep their current file. Changed from the default. Only for advanced users, add a test user and domain afterwards to check everything still works.
